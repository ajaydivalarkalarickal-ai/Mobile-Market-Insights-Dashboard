# Mobile Market Insights Dashboard

A Power BI data analytics project designed to explore the 2024 smartphone market through an interactive business intelligence dashboard.

## Project Objective

The project transforms a mobile-device dataset into an easy-to-understand dashboard for exploring smartphone pricing, specifications, product characteristics, and market patterns.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## Dashboard Focus

The dashboard is designed to help users explore mobile-market information and compare devices through interactive visuals and filters. The project demonstrates the process of preparing source data, building a Power BI data model, creating measures, and presenting information in a business-friendly dashboard.

## Repository Contents

- `Latest Mobile Dataset (2024).xlsx` — source dataset
- `Mini Project Data Analytics.pbix` — Power BI project file
- `Mini Project Data Analytics.pdf` — exported dashboard/report

## Skills Demonstrated

`Power BI` • `Power Query` • `DAX` • `Data Analysis` • `Dashboard Design` • `Data Visualization` • `Excel`

## Business Value

Interactive dashboards make it easier to turn large product datasets into structured information that supports comparison, trend identification, and data-driven decision-making.

## Learning Outcome

This project strengthened my practical experience in building Power BI dashboards from raw source data and presenting analytical information in a clear, decision-oriented format.
